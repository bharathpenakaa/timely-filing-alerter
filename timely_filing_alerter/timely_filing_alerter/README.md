# Timely Filing Alerter

Warns billing teams about healthcare claims nearing (or past) a payer's timely filing deadline.

## Run
    python timely_filing_alerter.py

Requires Python 3.8+. No external packages.

## Output
- Ranked console report
- timely_filing_alerts.csv

## Note
Payer filing limits in PAYER_RULES are illustrative. Replace with limits from your payer contracts.
